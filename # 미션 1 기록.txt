Q1. 👤 누가 쓰나요?
본인 혼자 쓸 건가요, 아니면 친구들과도 공유할 건가요?
(예: "나 혼자 내 PC에서만 쓸 거야" / "친구한테 링크 보내서 보여주고 싶어")
Q2. 🏆 등급(티어)은 몇 개로 나눌까요?
흔한 방식 예시:

5개: S, A, B, C, D
4개: 최고, 좋음, 보통, 별로
3개: 추천, 보통, 비추천
또는 본인이 원하는 방식
👉 몇 개로, 어떤 이름으로 할지 알려주세요.

Q3. 🖱️ 영화를 어떻게 등급 칸으로 옮기고 싶어요?
옵션 A: 드래그 앤 드롭 (마우스로 끌어다 놓기) — 멋있지만 조금 복잡
옵션 B: 영화 클릭 → 버튼으로 "S칸으로 보내기" 선택 — 단순하고 확실
옵션 C: 드롭다운 메뉴에서 등급 선택

Q4. 💾 브라우저를 껐다가 다시 열면 내가 정한 등급이 남아있어야 하나요?
예: 다시 열어도 그대로 → 저장 기능 필요 (브라우저 저장소 사용)
아니오: 열 때마다 처음부터 새로 → 저장 기능 없음

Q5. 🖼️ 영화는 화면에 어떻게 보여야 하나요?
옵션 A: 제목만 글자로 (예: [ 기생충 ]) — 간단하고 빠름
옵션 B: 포스터 이미지 + 제목 — 예쁘지만 이미지 파일을 직접 준비해야 함
옵션 C: 이모지나 색깔 박스 + 제목 — 심플하면서 꾸밈

Q6. ➕ 영화를 직접 추가/삭제 할 수 있어야 하나요?
아이디어.md 에 영화 8개가 있는데, 나중에 본 영화를 더 넣고 싶을 수도 있잖아요.
예: 입력창에 제목 적고 "추가" 버튼 → 목록에 생김 / 삭제도 가능
아니오: 처음 8개 영화 고정, 추가·삭제 불가

Q7. 📤 "친구에게 공유" 는 어떻게 하고 싶어요?
(Q1에서 가끔 공유하고 싶다고 하셨잖아요)

옵션 A: 그냥 화면 캡처해서 보내기 — 가장 간단, 추가 기능 없음
옵션 B: 내가 정한 등급을 텍스트로 복사해서 카톡에 붙여넣기 — 간단한 복사 버
